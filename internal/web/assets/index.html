Improve the model

Corrections you make while reviewing are saved here, each one pairing a short audio clip with the text you confirmed. Sent back, they are used to make the speech model better at this kind of material.

The file is saved to your computer — nothing is sent anywhere on its own. Send it on however you like, or keep it.

What is in the file

corrections/dataset.jsonl one line per reviewed span: the original text, your correction, and why it was flagged
corrections/clips/ the few seconds of audio each correction refers to, 16 kHz mono
transcripts/ the engine's own output, including how confident it was on every word
README.txt / manifest.json a plain description of the above, and which recordings it came from

Default folders

WAVs are written to <output>/audio/ and <output>/video/ so identically named sources cannot overwrite each other.
